# ShadowFi

Private Cross-Chain Lending Protocol powered by Ika + Encrypt.

## Overview

ShadowFi enables encrypted lending positions and hidden liquidation logic on Solana.

## Features

- Encrypted lending positions
- Health factor calculation
- Risk classification (Safe / Risky / Liquidatable)
- Auto liquidation simulation
- dWallet integration (Ika mock)

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS

## Run Locally

```bash
cd apps/web
npm install
npm run dev
```
