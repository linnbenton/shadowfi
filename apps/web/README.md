# 🌐 ShadowFi Web Interface

This is the Next.js frontend for the ShadowFi protocol, built with Tailwind CSS and integrated with Encrypt/Ika simulations.

## 🛠 Features

- **3-Panel Dashboard:** Multi-chain asset gateway, core lending engine, and privacy logs.
- **REFHE Integration:** Simulates encrypted debt positions and health factor monitoring.
- **MPC Interface:** Visualizes Ika dWallet creation and cross-chain signatures.

## 🚀 Development

Install dependencies:

```bash
npm install
```
